## 关键路径包（已落地）

标星即冻结路径包，工程落点二选一、禁止并存（台参数 `path_landing`）：

- **不可变快照 `snapshot`**：标星当下锁死节点序与边指纹，库级触发器禁止改写/删除。
- **影子草稿 `shadow`**：路径包收在草稿表，供影响页只读引用。

约束与联动：

- 标星入口（节点目录右侧）单次落定所选落点，所选落点与现行口径不一致、重复标星、起止之间无已发布路径均以中文报错。
- 影响分析：根节点有路径包时只沿冻结路径展开，否则走全图；作业记录 `path_source` / `path_length` / `path_fingerprint`。
- 关系页给每条边打路径来源芯片；影响页给出同源路径长度与路径行。
- 路径指纹与现行边不一致（漂移）时，续采编排与影响开跑均拦住并留痕。
- 标星与续采编排走 `BEGIN IMMEDIATE` 排他写锁，两名仓管抢标同一路径只有一方成功。
